Expand description

State that is shared across all windows. This includes settings, themes, and sync-related state.

Fields§

§settings: Arc<Mutex<Settings>>

Settings (shared across all windows)

§settings_version: Arc<AtomicU64>

Settings version counter, incremented whenever settings change. All windows check this to detect when they need to reload settings.

§themes: Arc<Mutex<Option<Themes>>>

Available themes

§sync_states: Arc<RwLock<HashMap<ProfileId, Arc<SyncState>>>>

Per-profile sync states keyed by profile id.

§sync_initialized: Arc<AtomicBool>

Global flag to ensure sync bootstrap runs only once across all windows.

§sync_error: Arc<Mutex<Option<String>>>

Synchronization initialization error (if key generation failed)

§update_info: Arc<Mutex<Option<UpdateInfo>>>

Update info if available

§pending_files_from_macos: Arc<Mutex<Vec<PathBuf>>>

Files from macOS “Open with” events (already Arc<Mutex>)

§http_agent: Arc<Agent>

Shared HTTP agent for connection pooling across all short-lived REST requests (token, ping, share fetch). Carries a 10s global timeout.

§sse_http_agent: Arc<Agent>

Dedicated HTTP agent for the long-lived SSE stream only.

§ssh_session_cache: Arc<Mutex<SshCredentialCache>>

Session-scoped SSH password cache keyed by (host, port, user).

The cache is memory-only and dropped on app exit.

§ssh_session_pool: Arc<SshSessionPool>

Process-wide pool of authenticated SSH sessions used to amortize TCP + SSH handshakes across successive remote operations.

§state_writer: Arc<StateWriter>

Dedicated background writer for WindowsState persistence.
