RAII ownership for long-lived background worker threads.

Blocking workers (SSE streams, the state writer, the IPC listener) cannot be cancelled by dropping a future, so their lifecycle used to rely on every exit path remembering to set the right AtomicBool. Worker makes the lifecycle structural: the struct owns the shutdown signal and the thread’s JoinHandle, and dropping it signals the worker, runs an optional wakeup to unblock a blocked read or accept, and joins with a bounded timeout. Storing the Worker in the state that owns the work guarantees that killing the owner kills the worker.
